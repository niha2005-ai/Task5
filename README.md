# Titanic Dataset Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn.

The objective is to analyze passenger information, identify patterns, visualize relationships between variables, and determine factors influencing survival.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information

- Total Records: 891
- Total Features: 12

## Key Findings

- Female passengers had a survival rate of 74.20%.
- Male passengers had a survival rate of 18.89%.
- First Class passengers had the highest survival rate (62.96%).
- Third Class passengers had the lowest survival rate (24.24%).
- Gender and Passenger Class were the strongest predictors of survival.
